# APP HR Online — Windows

Desktop wrapper for APP HR Online v1.6.0.

- Same Supabase backend as Android
- Same users and access permissions
- Purchase request module
- Windows Save As for XLSX exports
- Native Windows notifications
- Windows 10/11 x64 installer

The web UI is copied from:
`app/src/main/assets/www/index.html`

Build:
```
npm install
npm run dist
```
