# APP Intermediate Stock — Android

نسخه اندروید ثبت موجودی تولید و انبار میانی آلیاژ پردازش پارسه.

## ساخت APK با GitHub

1. فایل‌های این پوشه را در شاخه `main` مخزن قرار دهید.
2. صفحه `Actions` مخزن را باز کنید.
3. گردش `Build Android APK` را انتخاب و `Run workflow` را بزنید.
4. پس از سبز شدن اجرا، در پایین صفحه بخش `Artifacts` فایل
   `APP-Intermediate-Stock-Android-v1-debug` را دانلود کنید.
5. ZIP دانلودشده را باز و `app-debug.apk` را روی گوشی نصب کنید.

این خروجی برای آزمون داخلی است. برای انتشار و به‌روزرسانی بدون حذف اطلاعات،
نسخه Release باید با یک کلید امضای دائمی شرکت ساخته شود.

## نکات داده

- اطلاعات موجودی داخل فضای اختصاصی برنامه روی گوشی نگهداری می‌شود.
- حذف برنامه، پاک‌کردن Storage یا نصب خروجی با امضای متفاوت ممکن است داده محلی را پاک کند.
- فایل `.appstockbak` را مرتب در فضای دیگری نگه دارید.
- ذخیره فایل روزانه و بک‌آپ از پنجره استاندارد اندروید استفاده می‌کند.
